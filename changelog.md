# Changelog

## 1.2.0 — Final polish

### Code quality
- Reworked the CSS into a consistent design-token system.
- Normalized spacing, typography, borders and interaction states.
- Refactored JavaScript into small initialization modules.
- Hardened localStorage access for restricted browser environments.
- Improved navigation, theme handling, filtering and form behavior.
- Added a dedicated central configuration for brand and contact links.
- Removed duplicated font loading from the page markup.
- Reformatted all HTML files for maintainability.

### UX and accessibility
- Added keyboard-visible focus treatment.
- Added skip navigation.
- Added active navigation state with `aria-current`.
- Added reduced-motion handling.
- Added meaningful controls and labels for the mobile navigation and theme switcher.
- Made contact details actionable with email, telephone and social links.

### Product polish
- Refined responsive breakpoints, card states and surface hierarchy.
- Added a compact 430px mobile breakpoint for smaller phones.
- Kept visual artwork CSS-based so the template remains lightweight.
- Expanded documentation for customization and production handoff.

## 1.1.0 — Clean release

- Centralized styles and scripts.
- Added theme persistence, mobile navigation and course filtering.
- Added favicon, metadata and documentation.
- Added responsive and reduced-motion support.
