# Getting Started

VOX is a static template. There is nothing to install.

## 1. Preview

Open `index.html` in a modern browser.

For local development, any static server can be used. For example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## 2. Personalize

Edit `assets/js/config.js` first. This covers the values that commonly change from project to project.

For deeper changes, edit the page HTML and the design tokens in `assets/css/main.css`.

## 3. Deploy

Upload the complete folder to your static host. The template does not depend on a build pipeline.

## 4. Production checklist

- [ ] Replace demo content
- [ ] Replace contact information
- [ ] Connect the form
- [ ] Add real social URLs
- [ ] Add Open Graph image metadata
- [ ] Test all responsive breakpoints
